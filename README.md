# 怪兽研究所 · KAIJU LAB

你是哪一只奥特怪兽？选一张照片，在 30 类怪兽中匹配你的专属身份，解锁能力介绍。

**[点击体验 →](https://lynn-sunset.github.io/ultraman-kaiju-lab/)** 无需安装，手机和电脑都能使用。

- **照片匹配**：通过深度学习模型为怪兽类别打分，揭晓得分最高的怪兽身份，并查看匹配排名。
- **能力档案**：了解对应怪兽的称号、招牌技能和背景介绍。
- **怪兽图鉴**：浏览 30 类角色，支持名称搜索和年代筛选。
- **保存与分享**：下载专属 PNG 身份卡，方便分享给朋友。

照片和匹配结果仅在你的浏览器中处理，本站不会上传、保存或用于模型训练。身份卡不包含你的照片；只有主动保存身份卡时，才会生成文件并下载到本机。托管平台 GitHub 会为安全目的记录访问 IP。

结果仅供娱乐，不代表真实身份、性格或能力。本项目为非官方同人作品，角色及图片版权归原权利人所有。
