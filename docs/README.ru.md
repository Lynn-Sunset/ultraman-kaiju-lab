# Лаборатория кайдзю · KAIJU LAB

[简体中文](../README.md) · [日本語](README.ja.md) · [English](README.en.md) · [Español](README.es.md) · **Русский**

Какой ты кайдзю из «Ультрамена»? Выбери фото, чтобы найти своего двойника среди 30 монстров и узнать о его способностях.

**[Попробовать →](https://lynn-sunset.github.io/ultraman-kaiju-lab/)** Игра работает на телефоне и компьютере без установки.

- **Подбор по фото.** Нейросеть выставляет оценку каждому кайдзю. Узнай, кто набрал больше всего баллов, и посмотри весь рейтинг.
- **Профили кайдзю.** Познакомься с прозвищами, фирменными приёмами и историями монстров.
- **Каталог кайдзю.** Изучи всех 30 монстров, найди нужного по имени или выбери эпоху.
- **Карточка на память.** Скачай карточку своего кайдзю в формате PNG и поделись ею с друзьями.

Фото и результаты обрабатываются только в твоём браузере. Сайт не отправляет их на сервер, не хранит и не использует для обучения модели. Твоего фото на карточке нет. Файл создаётся и скачивается на устройство только тогда, когда ты выбираешь сохранение карточки. Хостинг GitHub записывает IP-адреса посетителей в целях безопасности.

Результаты предназначены для развлечения и не отражают твою реальную личность, характер или способности. Это неофициальный фанатский проект. Права на персонажей и изображения принадлежат их правообладателям.
