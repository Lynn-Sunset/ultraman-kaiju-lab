# 怪獣研究所 · KAIJU LAB

[简体中文](../README.md) · **日本語** · [English](README.en.md) · [Español](README.es.md) · [Русский](README.ru.md)

あなたはどのウルトラ怪獣？ 写真を1枚選ぶと、30種類の怪獣の中からあなたにぴったりの1体が見つかり、その能力を知ることができます。

**[試してみる →](https://lynn-sunset.github.io/ultraman-kaiju-lab/)** スマートフォンでもパソコンでも、インストールせずに遊べます。

- **写真でマッチング**：深層学習モデルが怪獣ごとにスコアを計算します。最高得点の怪獣と、ほかの怪獣の順位を確認できます。
- **怪獣プロフィール**：怪獣の別名、得意技、背景を紹介します。
- **怪獣図鑑**：30種類の怪獣を名前で検索したり、登場した時代で絞り込んだりできます。
- **保存とシェア**：自分の怪獣カードをPNG形式でダウンロードして、友だちにシェアできます。

写真とマッチング結果はブラウザー内でのみ処理されます。このサイトが写真や結果をアップロード、保存したり、モデルの学習に利用したりすることはありません。カードに写真は含まれません。保存を選んだときだけ、カードが生成され、端末にダウンロードされます。ホスティング元のGitHubはセキュリティのため、アクセス元のIPアドレスを記録します。

結果は娯楽目的で、実際の身元や性格、能力を示すものではありません。本プロジェクトは非公式のファン作品です。キャラクターおよび画像の権利は各権利者に帰属します。
